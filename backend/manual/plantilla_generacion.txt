REGLAS
===========================================================================

GUION

- El campo "guion" contendrá únicamente la narración.
- Sin títulos.
- Sin Markdown.
- Sin explicaciones.
- Duración según el Manual Maestro.

PLAN VISUAL

- "plan_visual" contendrá exactamente 8 elementos.
- Esos 8 elementos corresponden únicamente a las imágenes variables del caso.
- No incluyas la Imagen 9: es el sello maestro fijo de cierre y la aplicación
  lo añadirá automáticamente durante 3 segundos después de terminar la voz.

Cada elemento tendrá:

- numero
- frase_entrada
- tipo
- generar_ia
- buscar
- motivo
- edicion
- prompt

La "frase_entrada":

- será una cita literal, continua y sin puntos suspensivos tomada del guion;
- aparecerá una sola vez en el guion;
- comenzará al principio de una palabra;
- tendrá entre 6 y 14 palabras siempre que sea posible;
- respetará el orden narrativo de las imágenes 1 a 8;
- marcará el comienzo del contenido que representa esa imagen;
- en la Imagen 1 comenzará exactamente con la primera palabra del guion;
- la Imagen 1 representará el gancho o el tema general y seguirá siendo
  pertinente durante los 3 segundos completos de portada;
- en la Imagen 2 comenzará muy pronto, para que su contenido ya esté activo
  cuando termine la portada en el segundo 3;
- en las Imágenes 3 a 8 marcará el punto exacto en el que debe entrar la imagen.

Cada imagen representará únicamente el fragmento comprendido desde su
"frase_entrada" hasta la "frase_entrada" de la imagen siguiente. No asignes a
una imagen un hecho narrado antes o después de su tramo.

TIPO solo puede ser:

- FOTOGRAFIA_REAL
- RESTAURACION
- RECREACION_IA

Si el tipo es FOTOGRAFIA_REAL:

- generar_ia = false
- buscar tendrá entre 3 y 6 búsquedas.
- prompt será una cadena vacía.

Si el tipo es RESTAURACION:

- generar_ia = false
- buscar tendrá entre 3 y 6 búsquedas.
- prompt será una cadena vacía.

Si el tipo es RECREACION_IA:

- generar_ia = true
- buscar será un array vacío.
- prompt contendrá el prompt completo para GPT Image.

MUSICA

El campo "musica" contendrá únicamente el prompt para Suno.

MINIMAX

El campo "minimax" contendrá únicamente el prompt para MiniMax.

PUBLICACION

El objeto "publicacion" contendrá:

- titulo
- descripcion
- hashtags (máximo 5)
- comentario_fijado

No añadas ningún otro campo.
No añadas comentarios.
No añadas explicaciones.
Devuelve únicamente el JSON.
